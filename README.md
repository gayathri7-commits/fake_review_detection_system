# 🛡️ ReviewGuard - AI-Powered Fake Review Detection System

ReviewGuard is an intelligent web application engineered to detect fraudulent, spam, and AI-generated e-commerce product reviews. By evaluating text patterns and contextual cues, ReviewGuard helps consumers separate genuine buyer experiences from paid or automated feedback loops.

🚀 **[Live Demo](https://fake-review-detection-system-three.vercel.app/)**

---

## 🌟 Key Features

* **Dual-Input Analysis:** Accepts both direct product URLs (optional) and raw review text for deep content evaluation.
* **Pre-Baked Sample Testing:** Includes interactive quick-test samples (*Fake Enthusiastic*, *Genuine Detailed*, *Generic Spam*) allowing users to evaluate the system's detection capabilities instantly.
* **Modern Minimalist UI:** Designed with a clean, trust-centric blue and grey layout focused entirely on readability and a smooth user experience.
* **Fast and Lightweight:** Built on top of a highly optimized runtime engine for rapid response processing.

---

## 🛠️ Modern Tech Stack & Tooling

* **Runtime & Package Manager:** Powered by **Bun** for lightning-fast installation speeds, dependency resolution, and execution scripts.
* **Component System:** Configured with modern component primitives (`components.json`) for highly accessible, interactive UI layouts.
* **Styling Suite:** Implemented using a modern utility-first CSS structure to maintain sharp design rules across mobile and desktop displays.
* **Build System & Linter:** Bundled via **Vite** and audited with **ESLint** to secure a reliable, error-free production build.
